          $ cat how-it-works.txt
          
    1. it reads ~32,000 real first names.
2. for every letter, it notes which letter came right after it, and how often.
   after "q" it nearly always sees "u". names often end after "a" or "n".
3. to make a name: pick a first letter the way real names do, then keep
   picking the next letter based ONLY on the one before, until it stops.
4. that's it. it has no idea what came two letters back, hence "staiyaubrtthrigotai".
   big AI models use the same idea, but look much further back.

mode count    = it literally tallied the pairs.
mode practice = it started with random guesses and corrected itself 1,000 times,
                which is how bigger AI models learn. both end up almost identical.
